## Como usar
1. Fazer a **DATAPREV 2024** como simulado cronometrado (é o espelho mais fiel).
2. Corrigir pelo `dataprev_gabarito_definitivo-1.pdf`.
3. Usar TJ-RR e TCE-SE como banco extra de questões FGV de segurança.
4. Anotar tópicos errados no `../estudos/cronograma.md` (revisão 24h).
